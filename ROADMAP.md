# Roadmap

The preview provides ordered checkpoints, real actions and verification, manual
adoption, guarded controls, cleanup, CLI, optional React panel, optional Director window and safe receipts.
The independent task-app example proves the ordinary developer path.

Next, observe outside developers following the guide and authoring a journey.
Fix actual configuration, verification and cleanup friction. Improve diagnostics
without collecting application secrets. Ship small patches with reproduction cases.

Toward 1.0, establish repeated independent use, a proven compatibility matrix and
a reproducible release process. Document any API changes. A stable-release date
depends on evidence rather than feature count.

No planned hosted service, workflow graph, plugin registry, history database or
theme framework. Additional examples and adapters need demonstrated demand.
