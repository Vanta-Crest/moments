# Security

Use Moments only in environments you are authorized to exercise. Config and
drivers execute trusted local code. The bridge is limited to the runner-owned
main frame at the configured origin; it is not production authorization.

Before public launch, enable GitHub private vulnerability reporting. Use that
private channel for vulnerabilities; omit credentials and customer data from
public issues. The preview has no long-term support branch; upgrade to the current
preview for security fixes.
