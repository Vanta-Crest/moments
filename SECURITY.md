# Security

Use Moments only in environments you are authorized to exercise. Config and
drivers execute trusted local code. The bridge is limited to the runner-owned
main frame at the configured origin; it is not production authorization.

Report vulnerabilities privately with **Report a vulnerability** on the
repository's Security tab, not in a public issue. Omit credentials and customer
data. A recording or failure evidence can show anything that was on screen:
never attach one to a public issue. The preview has no long-term support branch; upgrade to the current
preview for security fixes.
